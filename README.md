# Build in public · Michael Alves

I'm moving from digital marketing (Google Ads, tracking, local SEO) into **Python and applied AI**, in Madrid.
I'm a beginner in Python and I'm doing a Master's in AI (started October 2026).

This repository is my **public build log**. It shows *what* I build, *why*, the decisions and the lessons, with real numbers.

> **There is no source code here, on purpose.** Some projects run my own business and hold private data,
> so the code stays private. Here you find the idea, the architecture, the decisions and the results.
> Projects with public code have their own repositories (links below).

## How I work

I build with **Claude Code**, an AI coding agent. The AI writes most of the code.
I decide what to build and why, set the rules (privacy, costs, what needs my approval), check the tests and use the result every day.
Every page here says what the AI did and what I decided.
